## 一、风格迁移实验（各取所长的实证，2026-09-05）

从决策人喜欢的 qwen3.8-max 页面实测提取视觉基线（米白纸底 #F4F2EA / 墨蓝侧栏 #0B1424-17253E / 墨蓝文字 #101A2B / 金色点缀 #C29933-#E3B54A / 衬线标题 / 点阵纸纹），作为生成提示注入 minimax-m3 重出同题看板：

| 评审项（kimi vision） | 注入版 minimax | 参照 qwen3.8-max | 原版 minimax |
|---|---|---|---|
| 质感与完成度 | 8/10 | 7.5/10 | 8/10 |
| 数据模块/图表表现力 | 8/10 | 7/10 | 8/10 |
| 是否纸金墨蓝沉稳风 | **是（完全符合）** | 是 | 接近（科技蓝，SaaS 风） |

**结论：qwen 的质感与 minimax 的模块表现力可兼得**——把 qwen 风格基线注入 minimax 提示词即可（不增加模型成本，仅 prompt 加 ~1k token）；同时 minimax 原版的通用蓝紫 SaaS 观感被替换为律所沉稳调性。注入版残缺点：个别卡片红色描边突兀、下半留白——基线描述已可迭代修正。
实验资产：docs/evidence/type-eval/style-transfer/（风格基线注入.txt / 注入版-minimax-m3.html+png / 参照-qwen3.8-max.png）

## 二、分工（Tier 分层，按用途与频率）

| Tier | 用途 | 模型 | 风格处理 | 每页成本（实测口径） | 预估占比 |
|---|---|---|---|---|---|
| T1 主力 | 常规看板/中后台页/内部工具页（高频） | minimax-m3（¥2.1） | **注入 qwen 风格基线** | ≈¥0.08 | 70% |

## 五、v2 低饱和修订（2026-09-05 决策人纠正回合）

决策人指正「导航窗与数据模块颜色饱和度过高」→ 基线 v2（style-transfer/风格基线注入-v2低饱和.txt）追加饱和度硬约束：金色系整体降饱和（#E3B54A→#C9B27E 淡金仅点缀 / #C29933→#A88F55 灰金 / #A57C22→#8C7444）；导航激活项=深墨蓝底+暗金 2px 细条；环比徽标浅底深字；图表藏青+哑金+灰系（全页零 >0.55 饱和色）；状态标签弱对比浅底。
- minimax 重生成（thinking:disabled）实测：v2 页面零高饱和色（断言全过），kimi vision 复核——导航"沉稳内敛、饱和度很低"、数据模块"克制统一"、质感 8.5（v1 为 8.0）。
- **关键发现：minimax-m3 支持 `thinking:{"type":"disabled"}`** —— 关闭思考后完整 18KB 页面仅 6.1k 输出 token（开启思考时 40k-48k 仍截断）；T1 主力生产调用必须带此参数（每页成本 ≈¥0.05，且消除截断重试）。
- 遗留：minimax 页面下半留白偏大（内容约占视口六成）——下一版提示词加「内容高度利用、底部不留白」约束。

## 六、v3 修正（2026-09-05 决策人二次纠正回合：v2 越改越差，回退）

决策人贴图纠正：数据模块配色用回 qwen 第一版（图2 = 米黄底 + 白卡 + 钢蓝主 #3D5A8F + 灰 #8A8FA0 + 低饱和绿灰 #8FA38C + 金仅点缀的莫兰迪报表风），minimax 数据模块设计保留。根因复盘：v1/v2 把品牌金（--gold 系）误当数据主色注入，与 qwen 原版数据用色相反；v2 再降饱和成灰金 → 灰平无生气。
- v3 = 回 v1 页面方向 + 导航/数据色逐条按 qwen 原版实测样式（style-transfer/风格基线-v3-qwen实测规范.txt）：导航激活=金 20%→4% 渐晕底 + 3.5px 金渐变左条；图表钢蓝主 #3D5A8F、单根金柱高亮当月、环形钢蓝/灰/灰金/绿灰 muted 四色；状态浅底深字；环比浅底小三角。
- minimax(thinking:disabled) 生成：18.6KB 完整闭合，6.99k out token；断言：钢蓝到位/金点缀 ≤11 处（细条·单柱·文字）/无高饱和填充。
- kimi vision 复核：质感 8.5、模块 8.0——"配色体系基本满分复刻目标风格，金色克制、无高饱和事故"；遗留：下半屏留白、导航选中态区分度可再强化（下轮提示词补）。
