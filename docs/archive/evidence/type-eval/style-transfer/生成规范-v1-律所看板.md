# 律所经营看板 生成规范 v1（2026-09-05 定稿：决策人三轮审校 + minimax 实测 + kimi vision 复核）
> 用法：<看板任务描述> + 本规范全文 注入 minimax-m3（thinking 关、max_tokens 28000）即得同风格页面；
> 定稿样例 = 注入版-minimax-m3-定稿.html（含人工 CSS 微调：图例 nowrap）；
> 视觉基底来源：qwen3.8-max 原版实测样式（决策人钦定质感）+ minimax-m3 数据模块设计；
> 配色已按决策人三轮反馈收敛（禁高饱和、金仅点缀、钢蓝主）。

【视觉规范 v3（2026-09-05 决策人二次纠正：回 v1 页面方向；导航与数据模块配色严格照 qwen3.8-max 原版实测样式，不得自行演绎成艳色/灰平色）】

一、页面骨架（保持 v1 方向）
- 页面底：#F4F2EA 暖米黄（纸感）；卡片 #FFFFFF 白卡，1px 边框 #E4DFD1，圆角 8-10px，阴影 0 1px 3px rgba(16,26,43,.06)
- 卡片之间留白从容；整体气质：沉稳商务报表，律所调性

二、导航窗（照 qwen 原版样式，金色必须这样用）
- 侧栏底色：linear-gradient(188deg, #17253E 0%, #101A2E 46%, #0B1424 100%)
- 侧栏右上可加金色光晕 radial-gradient(420px 200px at 110% -8%, rgba(227,181,74,.16), transparent 70%)——透明度 ≤.16，宁缺毋滥
- 导航项默认：#9AA4BC 文字，18px 线性图标（细线图标，stroke 1.7）；hover：#E9EBF2 + 背景 rgba(255,255,255,.055)
- 导航激活项（当前页）：文字 #F5EDD6（淡金米白）；背景 linear-gradient(90deg, rgba(194,153,51,.20), rgba(194,153,51,.04))——金色只做 20%→4% 的渐晕底；左缘 3.5px 竖条 background: linear-gradient(180deg, #E3B54A, #A57C22)，圆角 3px
- 侧栏徽标（角标）：rgba(227,181,74,.16) 底 + #E3B54A 字 + 1px rgba(227,181,74,.35) 边
- 分组小标题：#5C6784，字距 3px
- 禁止：亮金实底高亮块、金色大图标、金色满底

三、数据模块配色（照 qwen 原版实测：钢蓝主 + 低饱和辅助，金只做点缀）
- 柱状图/趋势图主色：#3D5A8F（钢蓝）；数据网格线 #E5E0D2；需要第二序列用 #8A8FA0 灰
- 突出「最新/本月」柱：深金 #C29933 单根（仅一根）
- 环形图扇区：#3D5A8F / #8A8FA0 / #C29933 / #8FA38C（低饱和绿灰）——全部为 muted 低饱和，禁止高饱和撞色
- KPI 大数字：#101A2B 墨蓝黑；强调小标可用 #C29933 或 #8A6A14 深金（只做文字/细线，不做底）
- 状态标签：浅底深字——如 #F1EDDF 米金底 #5A4A2A 字；「进行中」用低饱和绿 #3FA97C 小圆点 + 深灰绿字；不用亮底白字
- 环比徽标：浅底深字小徽标（如 #E8E4D8 底 #6B6A4E 字），正负用小三角（正 #3FA97C、负 #B07A62 低饱和陶红），禁止亮绿亮红实底
- 全页红线：禁止饱和度 >0.55 的填充色；金色为点缀色，占比 <5%；禁止把数据模块做成全金/全灰

【布局与内容约束（v5 修订，替代 v4 同名约束）】
- 页面总高目标 ≈ 1700-2000px（1440 宽约 1.2-1.4 屏），底部以页脚收尾（律所名称/©2026/最后更新日期/版本），任何区域不得出现 >300px 连续空白
- 卡片内部必须充实：任何卡片高度由其内容撑起，禁止卡片内大面积空腔（grid 卡片用 align-items:start 而非 stretch 撑空）
- 中排三卡等高：趋势图卡与环图卡、待办卡内容量均衡（趋势图高约 260px；待办列表 ≥6 条；环图旁配图例明细 ≥4 项）
- 「承办律师产能榜」：≥5 行且每行含 律师/在办件数/本季创收/完成率进度条/较上季变化；卡片底部加注「数据截至 2026-09-01」
- 「审限与待办提醒」：≥6 条，含 事项/关联案号/截止日/剩余天数（红橙金分级）/状态
- 「最近案件明细表」：≥10 行数据行（案号/客户/案件类型/承办律师/标的额/状态/最近动作）；表头浅米底
- 行距字距正常（不得用超大行高/超小字号充数），全部数据示例自洽（律所经营口径）
- 其余视觉规范（配色/导航/字体）严格照 v3 规范不变；禁止外链资源

【终版微调（v6）】
- 环形图图例：每项占位足够宽（图例列宽 ≥110px）并加 white-space:nowrap，禁止"进行 中/已归 档"式断行
- 中排三卡（趋势/分布/待办）内部垂直留白节奏统一：标题区、图表区、注脚区的上下间距一致（同类元素同 margin），卡片内容底部不留半空
- 其余全部照 v3 视觉规范 + v5 布局约束不变
