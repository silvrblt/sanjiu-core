# 评估任务：code-review / guard / S8 三套代码质量检查的分工安排

> 承办：一审承办 | 2026-09-03 | 立案庭路由：domain=framework_change → **组合 B（二审承办起步）**

## 一、三套工具的现状与真实关系（实证核查 2026-09-03）

| 工具 | 来源 | 机制 | 轴 | 触发 |
|---|---|---|---|---|
| **guard S8**（10 维度） | guard-skills 提炼 | 对抗审计 SYSTEM 材质注入 | 单轴：代码质量 | **硬注入**（全体对抗，v3.3.0） |
| **clean-code-guard 全量** | amElnagdy/guard-skills | 产出后自查 40+ 项 | 单轴：代码质量 | 软（自觉/高风险应跑） |
| **code-review**（mattpocock） | mattpocock skill 包 | **git diff 固定点双轴审查**：Standards（仓库编码规范）+ Spec（需求实现）并行子代理 | 双轴：规范+需求 | 软（MECH-08b 按需加载） |
| code-review-graph | MCP 图工具 | 大仓库定向读取省 token | 工具 | 软（护栏：抽样复核） |

**重叠结论**：三套质量检查并非纯重复——S8 ⊂ clean-code-guard（维度覆盖），code-review 是**另一个维度**（diff 对比 + 规范/需求双轴），与静态质量审查互补。真正重复的是 **S8 vs clean-code-guard 全量**（同为静态质量，S8 是它的 10 维度提炼版）。

## 二、候选方案

### 方案 A：维持现状三轨（S8 硬注入日常 + guard 全量高风险 + code-review 软按需）
- 对目的影响：零改动；但 S8/guard 重复未解（同一代码审两次质量）、code-review 仍靠自觉、三套维护。
- 成本：0；收益：无新增。

### 方案 B：归并分层（推荐候选）
- **S8 升级为完整质量清单的"精简注入层"**：日常对抗（A/B 全部）带 S8 10 维度（现状）；**组合 B 代码交付的对抗审计前置 = clean-code-guard 全量**（把"应跑"改"必跑"，替代 TRIGGER-RULES 软分级）——即 guard 从"软自觉"升"硬前置"，与 S8 成"日常精简 / 高风险全量"两级，消除重复（S8 与 guard 同源不并存同任务）；
- **code-review 保留独立定位但升级嵌入**：作为组合 B 代码交付的**对抗审计后置复核**（diff 双轴：规范+需求——与静态质量审查互补而非重叠）；触发从"按需自觉"改"立案庭路由标注 code-review 必跑"（B 组合代码类任务卡自动带该动作，软转硬流程）；
- 效果：每类代码任务恰好一套质量动作（A=对抗席 S8 内审；B=guard 全量前置 + code-review diff 双轴后置），无重叠无真空。

### 方案 C：全并入 S8（S8 扩为完整清单一次注入）
- 对目的影响：单一来源最简；但完整清单 40+ 项注入输入膨胀（对抗调用 ×0.5-1k token），且 code-review 的双轴 diff 能力 S8 无法覆盖（需 spec/git 上下文）——能力损失。
- 不推荐：S8 无法替代 code-review 的 diff 语义。

## 三、分歧与建议

1. **guard 全量触发方式（v3 修订，采纳 DS Pro）**：**guard 执行权归承办（产出自查，留结构化证据随材料送审）**；对抗审计席抽查证据真实性（不自证问题靠证据核查解决，非角色置换）；请终裁确认。
2. **code-review 后置复核的责任席（v2 补程序）**：二审对抗（DS Pro）执行 diff 双轴 → **一审承办 24h 异议申辩环节**（程序公正，doubao 意见）→ 三审 Qwen 复核收口；请终裁确认。
3. **S8 是否保留**：方案 B 下 S8 保留为日常精简层（A 组合唯一质量动作）——无分歧意见请确认。

## 四、验收（A-V）

- A1：方案 B 落地后，A 组合代码类对抗报告含 S8 检查项（现状维持）；B 组合代码交付材料含 guard 全量证据（传递物第 10 项，v3.3.0 已定义）
- A2：B 组合代码类任务卡含 code-review 动作标注（立案庭输出字段）
- A3（v3 抽样，风险分级定义 = 影响面×复杂度双阈值）：高风险 = 强制域代码或 >20 文件；中风险 = 常规业务 >3 文件；低风险 = ≤3 文件内部改动——覆盖三档各 ≥1 且 A/B 组合各半（≥4 任务）
- A3b：B 组合 guard 全量**执行率** = 100%（单一执行率口径：立案庭标注 → 承办执行 → 证据归档 → 月度统计；触发与执行合并计算）、code-review 后置执行率 = 100%；**申辩记录归档率 = 100%**
- D：落账 + 月度触发率统计（09-30；执行率 100% 达标）
- D2（终核 #5）：未达标自动立案复盘 + 冻结同类强制域任务至闭环
- D3（终核 #4）：统计唯一源 = 任务卡标注/证据链接/申辩记录；样本不足滚动补齐并记录豁免；缺字段计 0
