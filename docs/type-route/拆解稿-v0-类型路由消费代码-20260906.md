## 三、技术路径（代码设计 v0）

落点：`tools/court/route_task.py`（权威）+ `tools/route_task.py`（同内容收口）+ 运行位 `00_global-shared/tools/eep-tools/route_task.py`（同步）+ `sync-local.sh` 2b 清单追加两项 + 本拆解稿入仓。

新增函数（route_task.py 内，零新依赖，仅标准库 + yaml）：

1. `locate_models()`：搜索 [脚本同目录, 上级目录] 的 sanjiu-models.yaml（court/ 版在子目录，需 ../）；支持环境变量/`--models` 覆盖（无则自动探测）。
2. `load_verified(path)`：读 `candidate_pool.verified_models` → [{model, price_in, price_out, cache, vendor, types, note}]。
3. `rank_models(ttype, models, exclude_vendor=None)`：
   - 过滤：types 含 ttype（②测评达标）；exclude_vendor 非空时剔除同 vendor（①合规异厂）；
   - 排序：price_in 升序（③主锚）；±10% 同价档内按 price_out 升序（④次级锚，与老板 2026-08-15 拍板的九方排序口径一致；R4 原 0.7×达标度公式因 yaml 数据层无达标度数值字段而不可复现——**D2 分歧点**，降级实现如上并注明）；
   - 无 price_in 的模型（seedream 按张计费）不参与此层（image_gen 走 tool_seat 分支）。
4. `ui_design_tier()`：返回老板终裁 Tier 表（T1 minimax-m3 70% 注入基线+thinking disabled / T2 qwen3.8-max 20% / T3 glm-5.3 10%）——ui_design 类型不按价格序（**D1 分歧点**）。
5. `tool_seat_for(ttype)`：image_understand → vision_read 主备（cli glm-vision，primary glm-5.3-flash，alternates kimi-k3）；image_gen → image_gen 主备（cli ark-image，primary doubao-seedream-4-0-250828，冷备 cogview-4-250304）。注：工具席不经审级、视觉三级验收、独立记账。
6. main() 输出新增 `type_route` 字段：
   ```json
   {"decision": "ranked|tier|tool_seat|manual",
    "recommended": {"model": "...", "vendor": "...", "price_in": 0.0, "price_out": 0.0, "note": "..."},
    "candidates": [{...全量排序...}], "note": "..."}
   ```
7. `self_test()` 扩展三段：组合路由 10 项（保留）+ 类型判定 8 类 ≥2 样例 + compound 2 例（并列/零命中）+ 类型推荐断言 10 项（8 类各期望 top + exclude_vendor 1 项 + image 工具席 1 项）——纯规则零成本。

期望推荐（数据层推导，回测断言值）：
- code_gen → minimax-m3（2.1；达标：minimax-m3/doubao-2.1-turbo 3.0/doubao-seed-2.1-pro 6.0/kimi-k2.7-code 6.5/kimi-k2.7-code-highspeed 13）
- code_audit → hy3（1.0）；text_gen → glm-5.3-flash（0.8）；text_understand → hy3；data_analysis → hy3
- ui_design → T1 minimax-m3（tier）；image_understand → glm-5.3-flash（tool_seat）；image_gen → doubao-seedream-4-0（tool_seat）
- code_gen + exclude_vendor=minimax → doubao-2.1-turbo；compound → manual

## 四、分歧点（交对抗/裁决）

- **D1 ui_design 不走价格序走 Tier**：v0 采纳 Tier（老板终裁优先于通用排序）；对抗若坚持纯规则一致性 → 裁决。
- **D2 ④ 同价档性价比无达标度数值**：v0 降级 = ±10% 同档内 price_out 升序（口径与九方排序一致）；若要 R4 原公式需数据层加达标度字段（超出本次 scope，月度补测可带）。
- **D3 推荐语义**：v0 = 单层「任务执行模型」推荐（top+全候选），不落「类型×逐审级席位替换」（R3 远期形态，需 seats 层测评校准，另行）；异厂约束以 exclude_vendor 输入接口交给审计链调用方执行。
- **D4 遗留 tools/route_task.py 处置**：v0 = 与 court 版同内容收口（不删，防未知引用断裂；删除另行）；court 版 = 权威被引用版。
- **D5 文档同步**：终版说明 §三 未决清单 #1 状态更新（关闭）+ AGENTS.md §〇 不变（入口路径已指向 eep-tools）。
