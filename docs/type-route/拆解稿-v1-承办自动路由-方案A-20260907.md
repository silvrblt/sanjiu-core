## 二、技术路径

### 1. lead_route.py（tools/court/，主仓 + 运行位同步）

```
用法：
  lead_route.py <任务卡.json> [--out <回收路径>] [--force-model <model>] [--dry-run]
流程：
  1. 复用 route_task：classify_type + type_route（models/rules 同源加载）
  2. 决策分流：
     - manual（compound/未知扩展/空候选）→ 指引 exit 2
     - tool_seat（image_*）→ 工具席原链指引（glm-vision/ark-image cli）exit 2
     - tier（ui_design）→ 模板库指引（查 ui-design-library 索引 + 生成规范 v1 + thinking:disabled
       参数）exit 2——ui_design 有独立资产生成链（9/5 终裁 Tier 分工），不并入 lead_route 直调
     - ranked → 候选依序桥接承办（N2）
  3. 桥接调用：
     - model → CLI/api_id 解析：seats（9 席）model 精确命中取 (cli, api_id)；
       miss → vendor 推断 {zhipu: glm-audit, tencent: hunyuan-audit, minimax: minimax-audit,
       doubao: doubao-audit, moonshot: kimi, deepseek: deepseek-audit, aliyun: qwen-text-audit}，
       api_id = model（边界：非现役候选的长 api_id（doubao-seed-2-1-pro-260628 类）未内置——
       调用失败走降级链并提示人工确认）
     - 命令 = <cli> audit <任务卡> "<诉求>" --system <承办模板> --model <api_id>
       --max-tokens <默认 16384，命中 seats 取其 max_tokens> --no-compress --json
     - 承办模板 = tools/court/lead_prompts/lead-v1.txt（--system-file？CLI 无 --system-file，
       读文件后传 --system "<模板>"）
  4. 降级：失败（退出码≠0/产出空/网关错误）→ 同类型达标池下一候选；全败 exit 3 + 明确提示
  5. 产出：--out 文件写承办全文；stdout JSON {decision, model, chain, out, duration, note, cost_est}
退出码：0 成功 / 2 需人工或指引 / 3 候选全败回退当前会话
```
