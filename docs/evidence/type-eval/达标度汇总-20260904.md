- text_understand 要点 ≤8 条且每条 ≤30 字、7 关键事实：仅 DS-flash 1 条 36 字超限（7/7 命中但格式违规）；
- code_audit 植入 5 缺陷（注入/越权/浮点/句柄/吞异常），行号+特征双锚 ≥4/5 达标：DS-flash 与 doubao 各漏 1 处越权类缺陷（安全维度），余 6 模型 5/5；
- ui_design 结构闸（4 KPI/侧栏/趋势图/分布/明细表/无外链）：8/8 结构齐全；**视觉品质与月份轴样式差异留给双盲评分**；glm-5.3/qwen 单页 HTML 需 32k+ 预算（glm 29.3k out/8.2 分钟）——长文本生成成本高企的实证；
- 成本实录：重推理模型做生成/代码任务的实付为名义 2-20 倍（reasoning token 大头），96 笔台账可核。
